## 📊 Project Overview

This project analyses an E-commerce dataset to understand sales
performance and customer purchasing behaviour. The main objective is to
identify sales trends, popular product categories, customer preferences,
and patterns across cities, payment methods, and devices. Python was
used for data cleaning and exploratory analysis, and Power BI was used
to create interactive dashboards that present the findings clearly.

## 🗂️ Data Source

-   **Dataset:** Saturia -- E-Commerce Dataset
-   **Source:** Hugging Face
-   **Data period:** 2024--2025
-   **Number of rows:** 5000 Rows
-   **Number of columns:** 21

The dataset includes order and customer details, order date, age,
gender, city, product category, unit price, quantity, discount amount,
sales amount, payment method, device type, session duration, pages
viewed, returning-customer status, delivery time, customer rating, and
date-related fields (year, month, and month name).

## 🛠️ Tools & Technologies

-   **Programming language:** Python
-   **Data analysis:** Pandas, NumPy
-   **Data visualization:** Matplotlib, Seaborn
-   **Dashboard and reporting:** Microsoft Power BI
-   **Notebook environment:** Google Colab  Notebook

## 🧹 Data Cleaning & Preparation

The dataset was checked and prepared before analysis. The main steps
included: 1. Loaded the dataset using Pandas and reviewed its rows,
columns, and data types. 2. Checked for missing values and duplicate
records. 3. Checked duplicate order IDs separately. 4. Standardized
column names and cleaned extra spaces in text columns. 5. Converted the
order date column to a suitable date format. 6. Checked and corrected
data types where required. 7. Used the date column to work with year,
month, and month-name information. 8. Reviewed numerical columns and
checked distributions and skewness.
